# KTT 6Terusan 车间运营驾驶舱

## ① 快速上手

### 访问系统

打开 [{{BASE_URL}}/]({{BASE_URL}}/)，进入 KTT 6Terusan 车间运营驾驶舱。系统采用顶部导航，点击页面右上角的全屏按钮可扩大展示区域；右上角的 `LIVE · 演示数据` 标识表示当前正在查看演示数据。

### 界面导览

顶部导航共有 6 项：

- **驾驶舱**：先看在场车辆、工位状态、等待损失与需要关注的事项。
- **车间实时**：按入口、出口、待分配队列和工位卡片查看现场状态。
- **车辆进度**：按车辆/工单查看目标工时、已用工时、ETA 与风险状态。
- **延误根因**：查看延误分布、配件缺货排行、证据链和复核状态。
- **运营分析**：查看周转时间分布、A/B 班对比、工位热力图和任务类型效率。
- **PoC 验收**：查看数字如何回到采集事件、数据血缘、试点范围和验收阈值。

右上角的 `EN` 按钮用于切换英文界面；全屏按钮适合客户演示；`LIVE · 演示数据` 是当前数据状态标识，不代表正在接入客户现场数据。

建议按“驾驶舱 → 问题车辆 → 另一种风险 → 运营分析 → PoC 验收”的顺序浏览；需要看现场队列、车辆列表或延误明细时，再补充“车间实时 → 车辆进度 → 延误根因”。

## ④ 常见问题

### 1. 数据从哪里来？需要员工手工录入吗？

系统将车间摄像头识别到的进场、驶入/驶出、作业、暂停和恢复事件，与 WMS 的领料、库存等业务记录关联。演示过程中不要求员工逐项手工录入；进入真实 PoC 后，再按现场设备和 WMS 的实际接口核对数据血缘。

### 2. “待确认”和“待复核”是什么意思？

这表示当前证据还不足以把结论当成确定事实。系统会保留低置信识别、证据链和复核入口；完成摄像头、WMS 或人工复核后再更新状态。“待复核”不是系统报错，而是对不确定性的明确标注。

### 3. 系统会监控员工个人吗？

本阶段只展示班组级运营指标，不做个人绩效排名、个人工时或个人级红黄绿标记。个人级能力属于二阶段可选内容，必须单独完成授权、用途限定、访问审计和员工告知后才可启用。

### 4. 演示数据和真实数据有什么区别？

当前页面右上角的“演示数据”表示这是一套用于客户讲解的展示数据，数字用于说明页面、证据链和验收口径如何工作。正式 PoC 会接入客户现场摄像头和 WMS 数据，并用真实样本按车牌、工位事件和延误根因三条阈值验收；演示画面本身不能替代现场验收结果。

### 5. 手机上能不能看？

可以用手机访问 [{{BASE_URL}}/]({{BASE_URL}}/)，页面会按屏幕宽度重新排列内容；表格、热力图和车辆时间线信息较多，建议使用横屏或电脑查看完整细节。客户现场演示建议优先使用电脑或大屏。

### 6. 看到异常后应该怎么继续？

从驾驶舱点击车辆或导航进入车辆进度，再打开对应车辆详情查看时间线、摄像头截图、WMS 记录、置信度和复核状态。若要比较班组或查看趋势，进入运营分析；若要回看损失构成和验收口径，进入 PoC 验收页。
